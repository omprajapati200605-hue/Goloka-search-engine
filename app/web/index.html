Goloka only searches pages you add here. It reads the page you give it and the pages it links to on the same site, obeys robots.txt, and keeps nothing else.

Depth 0 reads only the first page. Depth 1 also reads the pages it links to.

Some sites refuse crawlers that do not identify themselves. If a crawl fails with HTTP 403, set GOLOKA_USER_AGENT in your .env file to a name with your contact details, then restart the server.
